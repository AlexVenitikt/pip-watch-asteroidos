# Contributing

## Workflow
1. Create feature branch from `main`.
2. Keep commits atomic and descriptive (conventional commits preferred).
3. Run local preview (`qmlscene`) before submitting PR.
4. Update docs when changing behavior or platform assumptions.

## Commit style
- `feat: ...`, `fix: ...`, `docs: ...`, `refactor: ...`, `chore: ...`

## Quality gates
- No proprietary/copyright-unclear assets.
- No build artifacts or secrets in commits.
- Keep ambient mode battery-friendly.
