# Manual QA Checklist

- First launch on clean AsteroidOS session.
- Theme switching through all six palettes.
- Faction/logo text visibility and map symbol readability.
- Character animation: walking/resting/reading behavior.
- Ambient fallback: animation disabled, high readability.
- Weather unavailable state displays `NO DATA`.
- Heart-rate unavailable state displays `N/A`.
- Steps unavailable state stays stable (no NaN/UI glitches).
- Tilt-to-wake transition normal <-> ambient.
- Charging + bluetooth disconnected visual states.
- 30-minute battery drain sanity check in normal mode.
